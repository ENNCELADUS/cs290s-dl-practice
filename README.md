# CS290S Deep Learning Practice

Welcome to the CS290S Deep Learning Practice course repository. This repository contains the materials, including lecture slides and hands-on projects, designed to help you gain practical experience with Deep Learning concepts.

## Repository Structure

The repository is organized into the following main directories:

### 📁 `lectures/`
Contains the lecture slides detailing theoretical concepts, modern deep learning architectures, and training pipelines.

### 📁 `projects/`
Contains the practical assignments and coursework projects where you will apply theoretical knowledge by training models on real datasets.

## Getting Started

To get started with the projects in this repository:

1. Navigate to the specific project directory inside `projects/` (e.g., `cd projects/project1-text-classification`).
2. Follow the `README.md` guidelines provided within the project folder. It will contain detailed instructions on the requirements, submission guidelines, and expected deliverables.
